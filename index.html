Two-Lane Workflow

LaunchPilot turns Telegram product ideas into pull requests. S.A.G.E. turns sage-fix and sage-small GitHub issues into reviewed automation runs. This dashboard is read-only; commands are handled in Telegram.

Read-only status

LaunchPilot

Telegram idea-to-website builds

Idea Lane
1 Telegram ideaIdea arrives with repo and website context.
2 Codex buildCodex scopes files, applies guardrails, and builds the change.
3 GitHub PRSummary, tests, and safety notes are posted for review.
4 Approve and mergeOwner approves in Telegram; LaunchPilot can merge the PR.
5 Open websiteLaunchPilot shares the Vercel or GitHub Pages link.

S.A.G.E.

Labeled GitHub issue-to-PR automation

Issue Lane
1 LabelApproved issue receives sage-fix or sage-small.
2 InspectAgent reads issue, repo policy, and current branch state.
3 PatchFocused implementation and checks run in isolation.
4 Request ReviewPR waits for human approval before merge.
